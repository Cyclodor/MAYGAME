# Инструкция по запуску BattleGame.exe на другом ПК

## Требования для запуска

### Обязательные компоненты:

1. **Windows 10 или Windows 11** (64-bit)

2. **Visual C++ Redistributable 2015-2022**
   - Скачайте и установите с официального сайта Microsoft:
   - https://aka.ms/vs/17/release/vc_redist.x64.exe
   - Это необходимо для работы Python приложений, собранных через PyInstaller

3. **Антивирус**
   - Некоторые антивирусы могут блокировать exe файлы, собранные PyInstaller
   - Добавьте BattleGame.exe в исключения антивируса, если он блокирует запуск

## Если игра не запускается

### Вариант 1: Включить консоль для отладки

1. Откройте файл `BattleGame.spec`
2. Найдите строку: `console=False,`
3. Измените на: `console=True,`
4. Пересоберите exe через `rebuild_battlegame.bat`
5. Запустите exe - теперь будет видно ошибки в консоли

### Вариант 2: Проверка зависимостей

Если игра не запускается, возможно отсутствуют DLL файлы. Проверьте:

1. Установлен ли Visual C++ Redistributable (см. выше)
2. Запустите exe из командной строки для просмотра ошибок:
   ```
   cd путь\к\файлу
   BattleGame.exe
   ```

### Вариант 3: Сборка с включенной консолью

Если нужно сразу собрать с консолью для отладки, измените в `BattleGame.spec`:
```python
console=True,  # Вместо console=False
```

## Альтернативный способ запуска

Если exe не работает, можно запустить через Python:

1. Установите Python 3.10 или выше
2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Запустите:
   ```
   python main.py
   ```

## Распространение игры

При распространении игры на другие ПК убедитесь, что:

1. ✅ Файл `BattleGame.exe` собран с `upx=False` (уже настроено)
2. ✅ Все необходимые ресурсы включены в exe (assets, data, debug)
3. ✅ Получатель установил Visual C++ Redistributable
4. ✅ Антивирус не блокирует файл

## Размер файла

- Ожидаемый размер: ~50-70 MB
- Это нормально для Python приложения с pygame и numpy

## Контакты для поддержки

Если проблема не решается, проверьте:
- Версию Windows (должна быть 10 или 11, 64-bit)
- Наличие Visual C++ Redistributable
- Логи ошибок (если включена консоль)
