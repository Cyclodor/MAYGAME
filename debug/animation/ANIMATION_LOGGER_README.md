# Логгер Анимаций - Руководство

## Описание

Система логирования анимаций автоматически записывает все анимации и эффекты, которые проигрываются во время игры, в файл `animation_log.txt`.

## Что логируется

### 1. **Анимации заклинаний**
```
[SPELL_ANIMATION] Заклинание: Молния (lightning) | Кастер: hero | Цель: skeleton | ТИП: Мгновенное (без снаряда)
[SPELL_ANIMATION] Заклинание: Огненный шар (fireball) | Кастер: hero | Цель: zombie | ТИП: С полетом снаряда
```

### 2. **Анимации снарядов**
```
[PROJECTILE_ANIMATION] Снаряд: magic_bolt | От (5, 3) к (8, 7) | Цвет: (120, 180, 255)
[FIREARROW_ANIMATION] Огненная стрела от hero к skeleton
```

### 3. **Начало раунда**
```
[ROUND_START] Раунд 2
```

### 4. **Применение и сброс защиты**
```
[DEFENSE_APPLIED] peasant: Защита 10->12, Физ.защ 15->18, Маг.защ 12->14, Сопр.маг 20->24
[DEFENSE_RESET] peasant: Защита 12->10, Физ.защ 18->15, Маг.защ 14->12, Сопр.маг 24->20
```

### 5. **Эффекты**
```
[EFFECT_ANIMATION] Эффект: Благословение | Цель: knight | Длительность: 3
```

## Расположение лог-файла

Файл `animation_log.txt` создается в корневой директории игры при запуске.

## Формат лога

```
[Время] (+секунд с начала) ТИП_АНИМАЦИИ | Подробности
```

Пример:
```
[10:49:20.509] (+0.01s) SPELL_ANIMATION | Заклинание: Молния (lightning) | Кастер: hero | Цель: skeleton | ТИП: Мгновенное (без снаряда)
```

## Отладка защиты

### Проблема
Ранее защита не сбрасывалась в начале нового раунда из-за проблем с округлением при делении.

### Решение
Теперь система:
1. **Сохраняет оригинальные значения** перед применением защиты:
   - `_original_defense`
   - `_original_phys_defense`
   - `_original_magic_defense`
   - `_original_magic_resist`

2. **Восстанавливает точные значения** в начале нового раунда

3. **Логирует все изменения** защиты для отладки

### Как проверить

1. Запустите игру
2. Используйте защиту на юните (кнопка с щитом)
3. Проверьте тултип - защита должна увеличиться на 20%
4. Дождитесь нового раунда
5. Проверьте тултип снова - защита должна вернуться к исходным значениям
6. Откройте `animation_log.txt` и найдите записи `DEFENSE_APPLIED` и `DEFENSE_RESET`

## Пример лога защиты

```
[10:50:15.123] (+45.23s) DEFENSE_APPLIED | peasant: Защита 10->12, Физ.защ 15->18, Маг.защ 12->14, Сопр.маг 20->24

[10:51:20.456] (+110.56s) ROUND_START | Раунд 2

[10:51:20.458] (+110.56s) DEFENSE_RESET | peasant: Защита 12->10, Физ.защ 18->15, Маг.защ 14->12, Сопр.маг 24->20
```

## Типы анимаций

### Мгновенные (без полета снаряда)
- `lightning` - Молния
- `weakness` - Слабость
- `bless` - Благословение
- `curse` - Проклятие
- `slow` - Замедление
- `haste` - Ускорение
- `heal` - Лечение
- `dispel` - Снятие чар
- И другие баффы/дебаффы

### С полетом снаряда
- `frost_ring` - Кольцо холода
- Магические болты от магов

### Специальные анимации
- `firearrow` - Огненная стрела (своя анимация)
- `fireball` - Огненный шар (анимация полета и взрыва)
- `earth_spikes` - Каменные шипы (анимация шипов)

## Отключение логирования

Если вы хотите отключить логирование, измените в `animation_logger.py`:
```python
self.enabled = False  # в __init__
```

Или вызовите во время игры:
```python
self.anim_logger.disable()
```

## Проверка временных файлов

В репозитории также есть тестовые файлы:
- `check_spell_animations.py` - проверяет типы анимаций заклинаний
- `test_defense_system.py` - тестирует систему защиты
- `animation_logger.py` - сам логгер

Запустите их для проверки:
```bash
python check_spell_animations.py
python test_defense_system.py
python animation_logger.py
```

## Известные исправления

✅ **Защита теперь правильно сбрасывается в начале нового раунда**
- Используются сохраненные оригинальные значения
- Нет потери точности при округлении
- Все параметры (физ., маг. защита, сопротивление) сбрасываются корректно

✅ **Молния и слабость не показывают анимацию полета снаряда**
- Эти заклинания помечены как мгновенные
- Их анимации проигрываются внутри самого заклинания

✅ **Все анимации логируются для отладки**
- Легко отследить какие анимации проигрались
- Видно время и последовательность событий
