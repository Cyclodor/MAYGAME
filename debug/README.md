# Папка отладки и диагностики

Эта папка содержит все файлы, связанные с отладкой, тестированием и диагностикой игры.

## Структура папок

### `berserker/` - Отладка руны берсерка
- `berserker_debug.py` - Модуль отладки берсерка
- `patch_berserker_debug.py` - Скрипт для автоматического патчинга кода для отладки
- `generate_berserker_report.py` - Скрипт для генерации отчета по отладке
- `berserker_debug.log` - Лог отладки берсерка (очищается при каждом запуске)
- `BERSERKER_DEBUG_README.md` - Документация по отладке берсерка
- `ИНСТРУКЦИЯ_БЕРСЕРК_ОТЛАДКА.txt` - Инструкция по использованию отладки

### `resurrection/` - Отладка воскрешения
- `resurrection_debug.py` - Модуль отладки воскрешения
- `resurrection_debug.log` - Лог отладки воскрешения

### `animation/` - Отладка анимаций
- `animation_logger.py` - Модуль логирования анимаций
- `animation_log.txt` - Лог анимаций
- `test_animation_log.txt` - Тестовый лог анимаций
- `ANIMATION_LOGGER_README.md` - Документация по логированию анимаций

### `logs/` - Прочие логи
- `indentation_errors.log` - Лог ошибок отступов

### `scripts/` - Скрипты проверки и тестирования
- `check_editor_params.py` - Проверка параметров редактора
- `check_indentation.py` - Проверка отступов
- `check_spell_animations.py` - Проверка анимаций заклинаний
- `test_defense_fixes.py` - Тест исправлений защиты
- `test_defense_system.py` - Тест системы защиты

### `docs/` - Документация по исправлениям
- `ИТОГОВЫЕ_ИСПРАВЛЕНИЯ.md` - Итоговые исправления
- `КРАТКАЯ_ИНСТРУКЦИЯ.md` - Краткая инструкция
- `FINAL_SPELL_EDITOR_FIX.md` - Финальные исправления редактора заклинаний
- `FIXES_SUMMARY.md` - Сводка исправлений
- `SPELL_EDITOR_IMPROVEMENTS.md` - Улучшения редактора заклинаний
- `SPELL_EDITOR_MANUAL_INPUT.md` - Ручной ввод в редакторе заклинаний
- `SPELL_EDITOR_UPDATE.md` - Обновление редактора заклинаний
- `UNIT_EDITOR_INPUT_BLOCK.md` - Блокировка ввода в редакторе юнитов

## Использование

### Отладка берсерка
1. Запустите `debug/berserker/patch_berserker_debug.py` для применения патчей
2. Запустите игру и воспроизведите проблему
3. Запустите `debug/berserker/generate_berserker_report.py` для генерации отчета
4. Проверьте `debug/berserker/berserker_debug.log` и сгенерированный отчет

### Отладка воскрешения
1. Запустите игру с включенной отладкой воскрешения
2. Проверьте `debug/resurrection/resurrection_debug.log`

### Отладка анимаций
1. Запустите игру с включенным логированием анимаций
2. Проверьте `debug/animation/animation_log.txt`

## Примечания

- Логи могут быть большими, рекомендуется периодически их очищать
- Скрипты проверки можно запускать независимо для диагностики проблем
- Документация содержит описание исправлений и улучшений игры
