# Улучшения редактора заклинаний

## Выполненные изменения

### 1. ✅ Книга заклинаний работает без героев

**Проблема:** Раньше вкладка "Книги заклинаний" была недоступна, если не созданы герои.

**Решение:** Теперь вкладку можно открыть в любое время:
- **Если героев нет** - показывается информационное сообщение с инструкцией
- **Если герои есть** - работает как обычно, можно добавлять/удалять заклинания

Сообщение при отсутствии героев:
```
Нет созданных героев

Создайте героев в режиме
креативного редактора,
чтобы добавлять им
заклинания в книгу
```

### 2. ✅ Формула урона для заклинаний

В редакторе заклинаний теперь отображается **формула расчета** для заклинаний урона и лечения:

#### Для заклинаний урона:
```
Формула урона: 20 + сила_магии × 5
Пример: при силе магии 3 = 35 урона
```

#### Для заклинаний лечения:
```
Формула лечения: 50 + сила_магии × 10
Пример: при силе магии 3 = 80 HP
```

**Формула обновляется динамически** при изменении параметров:
- Изменили урон → формула пересчитывается
- Изменили множитель → формула пересчитывается
- Всегда видно итоговый результат с примером

## Как использовать улучшенный редактор

### 1. Открытие без героев
1. Запустите игру
2. В главном меню выберите "Книги заклинаний"
3. Даже без созданных героев вы увидите:
   - Список всех доступных заклинаний
   - Фильтр по школам магии
   - Кнопку перехода в "Изменить параметры"

### 2. Изменение параметров заклинания
1. Перейдите в "Изменить параметры"
2. Выберите заклинание из списка слева
3. Справа увидите все параметры
4. **Для заклинаний урона/лечения** внизу появится **формула**:
   ```
   Формула урона: [базовый_урон] + сила_магии × [множитель]
   Пример: при силе магии 3 = [итого] урона
   ```
5. Измените параметры кнопками **-** и **+**
6. Формула автоматически обновится

### 3. Примеры работы формул

#### Огненная стрела (по умолчанию):
- Урон: 20
- Множитель: 5
- **Формула:** 20 + сила_магии × 5
- При силе магии 3: **35 урона**

#### Если увеличить множитель до 10:
- Урон: 20
- Множитель: 10
- **Формула:** 20 + сила_магии × 10
- При силе магии 3: **50 урона**

#### Воскрешение:
- Лечение: 50
- Множитель: 10 (при формуле воскрешения используется другой множитель)
- **Формула:** 50 + сила_магии × 10
- При силе магии 3: **80 HP**

## Технические детали

### Изменённые файлы:
- `game/core.py`:
  - Функция `draw_spellbook_editor()` - добавлена поддержка работы без героев
  - Функция `draw_spell_editor()` - добавлено отображение формул

### Формулы урона
Формулы отображаются автоматически для заклинаний, у которых:
- `damage > 0` И `spell_power_multiplier > 0` - для урона
- `heal_amount > 0` И `spell_power_multiplier > 0` - для лечения

### Цветовая кодировка формул:
- **Жёлтый (255, 255, 100)** - формула урона
- **Зелёный (120, 255, 120)** - формула лечения
- **Серый (200, 200, 150 / 150, 200, 150)** - примеры расчета

## Совместимость

Все изменения обратно совместимы:
- Старые сохранения работают
- Если параметр не указан в overrides, используется значение по умолчанию
- Можно удалить `spell_overrides.json` для сброса

## Преимущества

1. **Удобство**: Можно изучать заклинания без создания героев
2. **Наглядность**: Формулы показывают точный расчет урона/лечения
3. **Гибкость**: Все заклинания доступны для редактирования
4. **Прозрачность**: Видно, как изменения параметров влияют на результат
