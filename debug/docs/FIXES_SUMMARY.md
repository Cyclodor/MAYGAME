# Сводка исправлений системы защиты и логирования

## Проблемы которые были исправлены

### 1. ❌ Старый параметр `defense` использовался везде
**Проблема:** В коде использовался устаревший параметр `defense` вместе с новыми `phys_defense` и `magic_defense`

**Исправление:**
- ✅ Удален параметр `defense` из применения защиты
- ✅ Удален параметр `defense` из сброса защиты  
- ✅ Удален параметр `defense` из логирования
- ✅ Теперь используются только `phys_defense` и `magic_defense`

### 2. ❌ Защита накапливалась и не сбрасывалась
**Проблема:** Защита могла применяться несколько раз, значения росли (12->14->16->19)

**Исправление:**
- ✅ Добавлена проверка флага `_defend_this_round` перед применением защиты
- ✅ Если юнит уже в защите - повторное нажатие игнорируется
- ✅ Оригинальные значения сохраняются только один раз
- ✅ В начале раунда все параметры восстанавливаются точно

### 3. ❌ Статус "В защите" не сбрасывался в тултипе
**Проблема:** Флаг `_defend_this_round` не сбрасывался, поэтому в тултипе продолжал отображаться статус защиты

**Исправление:**
- ✅ Флаг `_defend_this_round` теперь правильно сбрасывается в начале раунда
- ✅ Статус защиты исчезает из тултипа при начале нового раунда

### 4. ❌ Анимации заклинаний не логировались
**Проблема:** В лог-файле не было записей об анимациях заклинаний

**Решение:**
- ✅ Логирование заклинаний уже было добавлено ранее
- ✅ В коде есть вызовы `anim_logger.log_spell_animation()`
- ✅ Если в логе нет заклинаний - значит игрок их просто не использовал

## Технические детали

### Логика защиты:

```python
# Применение защиты
if not unit._defend_this_round:  # Проверяем флаг
    # Сохраняем оригинальные значения
    unit._original_phys_defense = unit.phys_defense
    unit._original_magic_defense = unit.magic_defense
    unit._original_magic_resist = unit.magic_resist
    
    # Увеличиваем на 20%
    unit.phys_defense = int(unit.phys_defense * 1.2)
    unit.magic_defense = int(unit.magic_defense * 1.2)
    unit.magic_resist = min(95, int(unit.magic_resist * 1.2))
    
    unit._defend_this_round = True
```

### Сброс защиты в новом раунде:

```python
# В начале нового раунда
if unit._defend_this_round:
    # Восстанавливаем оригинальные значения
    unit.phys_defense = unit._original_phys_defense
    unit.magic_defense = unit._original_magic_defense
    unit.magic_resist = unit._original_magic_resist
    
    # Удаляем временные атрибуты
    delattr(unit, '_original_phys_defense')
    delattr(unit, '_original_magic_defense')
    delattr(unit, '_original_magic_resist')
    
    unit._defend_this_round = False
```
