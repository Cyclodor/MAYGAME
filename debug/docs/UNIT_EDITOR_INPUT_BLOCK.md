# Блокировка интерфейса в редакторе юнитов

## ✅ Исправлено

### Проблема
**Было:** Когда панель ручного ввода была открыта в редакторе юнитов, пользователь все еще мог:
- Кликать на расы (менять выбранную расу)
- Кликать на юнитов (менять выбранного юнита)
- Взаимодействовать с параметрами
- Нажимать кнопки "Сохранить" и "Назад"

**Проблема:** Обработка панели ввода была не в начале функции `handle_unit_editor_click()`, поэтому проверки других элементов интерфейса выполнялись раньше.

### Решение
Переместил обработку панели ввода **в самое начало** функции `handle_unit_editor_click()`, чтобы она имела **приоритет** над всеми остальными элементами.

**Стало:** Пока панель ввода открыта:
- ✅ Работают **только** кнопки панели ввода
- ❌ Нельзя выбрать другую расу
- ❌ Нельзя выбрать другого юнита
- ❌ Нельзя изменить параметры
- ❌ Нельзя нажать "Сохранить" или "Назад"

## Технические детали

### Было:
```python
def handle_unit_editor_click(self, pos):
    # Выбор расы (выполнялось первым!)
    if hasattr(self, 'unit_editor_race_rects'):
        ...
    
    # Выбор юнита (выполнялось вторым!)
    if hasattr(self, 'unit_editor_unit_rects'):
        ...
    
    # Панель ввода (выполнялось третьим!)
    if hasattr(self, 'num_input') and self.num_input:
        ...
```

### Стало:
```python
def handle_unit_editor_click(self, pos):
    # Панель ввода (выполняется ПЕРВОЙ!)
    if hasattr(self, 'num_input') and self.num_input:
        # Обрабатываем только кнопки панели
        ...
        # ВАЖНО: return блокирует выполнение остального кода
        return
    
    # Выбор расы (выполняется только если панель закрыта)
    if hasattr(self, 'unit_editor_race_rects'):
        ...
    
    # Выбор юнита (выполняется только если панель закрыта)
    if hasattr(self, 'unit_editor_unit_rects'):
        ...
```

## Как это работает

### 1. Панель ввода закрыта
```
Клик по расе → ✅ Раса меняется
Клик по юниту → ✅ Юнит меняется
Клик по параметру → ✅ Параметр изменяется
Двойной клик по значению → ✅ Открывается панель ввода
```

### 2. Панель ввода открыта
```
Клик по расе → ❌ Ничего не происходит
Клик по юниту → ❌ Ничего не происходит
Клик по параметру → ❌ Ничего не происходит
Клик по кнопке панели → ✅ Панель реагирует
Клик вне панели → ❌ Ничего не происходит (защита)
```

### 3. Логика блокировки
```python
if panel_open:
    # Обрабатываем только кнопки панели
    handle_panel_buttons()
    return  # ← КЛЮЧЕВОЙ момент! Выходим из функции
            # Весь код ниже НЕ выполнится

# Этот код выполнится ТОЛЬКО если панель закрыта
handle_other_interface()
```
