# Обновление системы заклинаний и редактора

## Что было сделано

### 1. Заклинание Воскрешения (Resurrection)
- Добавлен параметр `heal_amount` (базовое значение: 50 HP)
- Теперь заклинание может:
  - **Лечить живых юнитов** - если применить на живого раненого союзника
  - **Воскрешать мертвых юнитов** - если применить на труп
- Количество восстанавливаемого HP: `heal_amount + spell_power * 10`
- Не действует на нежить

### 2. Добавлены численные параметры для всех заклинаний

#### Лечащие заклинания:
- **HealSpell**: `heal_amount = 20`, `spell_power_multiplier = 5`
- **ResurrectionSpell**: `heal_amount = 50`, `spell_power_multiplier = 10` (косвенно)
- **UndeadHealSpell**: `heal_amount = 25`, `spell_power_multiplier = 5`

#### Заклинания урона:
- **FireArrowSpell**: `spell_power_multiplier = 5`
- **FireballSpell**: `spell_power_multiplier = 5`
- **FrostRingSpell**: `spell_power_multiplier = 5`
- **LightningSpell**: `spell_power_multiplier = 8`
- **EarthSpikesSpell**: `spell_power_multiplier = 6`

#### Баффы (положительные эффекты):
- **BlessSpell**: `buff_amount = 25` (процент увеличения атаки)
- **HasteSpell**: `speed_bonus = 2`, `initiative_bonus = 5`
- **RuneHasteSpell**: `speed_bonus = 2`, `initiative_bonus = 5`
- **RuneShieldSpell**: `defense_bonus = 15`
- **StoneSkinSpell**: `base_percent = 15` (базовый процент увеличения защиты)
- **IceShieldSpell**: `absorption_percent = 35`, `hp_bonus_percent = 5`, `defense_bonus_percent = 20`

#### Дебаффы (отрицательные эффекты):
- **CurseSpell**: `debuff_amount = 25` (процент уменьшения атаки)
- **SlowSpell**: `initiative_reduction = 5`, `speed_reduction = 1`
- **WeaknessSpell**: `debuff_amount = 30` (процент уменьшения атаки)

### 3. Расширенный редактор заклинаний

Редактор теперь показывает и позволяет изменять все следующие параметры:

1. **Урон** (damage) - базовый урон заклинания
2. **Мана** (mana_cost) - стоимость в мане
3. **Длительность** (duration) - длительность эффекта в ходах
4. **Лечение** (heal_amount) - количество восстанавливаемого HP
5. **Множитель силы** (spell_power_multiplier) - как сила магии влияет на эффект
6. **Баффы %** (buff_amount) - процент усиления для баффов
7. **Дебаффы %** (debuff_amount) - процент ослабления для дебаффов
8. **Замедление инициативы** (initiative_reduction) - величина уменьшения инициативы
9. **Замедление скорости** (speed_reduction) - величина уменьшения скорости
10. **Бонус скорости** (speed_bonus) - величина увеличения скорости
11. **Бонус инициативы** (initiative_bonus) - величина увеличения инициативы
12. **Бонус защиты** (defense_bonus) - фиксированный бонус к защите
13. **Базовый процент** (base_percent) - базовый процент для заклинаний с процентными эффектами
14. **Поглощение %** (absorption_percent) - процент поглощаемого урона
15. **HP бонус %** (hp_bonus_percent) - процент от макс HP для бонуса
16. **Защита бонус %** (defense_bonus_percent) - процент от защиты для бонуса

### 4. Как использовать редактор

1. В главном меню выберите "Редактор заклинаний"
2. Выберите заклинание из списка слева
3. Справа появятся все доступные параметры для этого заклинания
4. Используйте кнопки **-** и **+** для изменения значений
5. Изменения сохраняются автоматически в файл `data/spell_overrides.json`
6. Все изменения применяются к заклинаниям героев при старте боя

### 5. Технические детали

- Все параметры сохраняются в JSON файле для удобного редактирования
- Параметры применяются автоматически к заклинаниям через `_apply_spell_overrides_to_instance()`
- Редактор показывает только те параметры, которые есть у конкретного заклинания
- Цветовая кодировка помогает различать типы параметров:
  - Урон - оранжевый
  - Мана - голубой
  - Лечение - зеленый
  - Баффы - светло-зеленый
  - Дебаффы - красноватый
  - И т.д.

## Примеры использования

### Пример 1: Усиленное воскрешение
Если установить `heal_amount = 100` для Resurrection, заклинание будет:
- Лечить живых на 100 HP
- Воскрешать мертвых со 100 HP

### Пример 2: Мощная молния
Если установить `damage = 50` и `spell_power_multiplier = 15` для Lightning:
- При силе магии 3: урон = 50 + 15*3 = 95

### Пример 3: Сильное замедление
Если установить `initiative_reduction = 10` и `speed_reduction = 3` для Slow:
- Цель потеряет 10 инициативы и 3 скорости

## Совместимость

Все изменения обратно совместимы:
- Если параметр не указан в overrides, используется значение по умолчанию
- Старые сохранения работают без проблем
- Можно удалить `spell_overrides.json` для сброса к значениям по умолчанию
