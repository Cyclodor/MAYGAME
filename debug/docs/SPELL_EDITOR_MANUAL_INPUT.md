# Ручной ввод значений в редакторе заклинаний

## ✅ Реализовано

### 1. Изменение параметров по единице
**Было:** Параметры изменялись с разными шагами (урон на 5, баффы на 5, и т.д.)
**Стало:** Все параметры изменяются по 1 единице за клик на кнопки **-** и **+**

### 2. Панель ручного ввода значений
Добавлена полноценная панель для ввода значений вручную, как в редакторе юнитов.

#### Как открыть панель ввода:
1. Откройте редактор параметров заклинания
2. Выберите заклинание
3. **Дважды кликните** по значению любого параметра (синяя плашка с числом)
4. Откроется панель ввода

#### Возможности панели:
- **Цифровая клавиатура** 0-9 для ввода
- **Кнопка "Удалить"** - стирает последнюю цифру
- **Кнопка "OK"** - сохраняет значение
- **Кнопка "Отмена"** - закрывает панель без сохранения
- Ввод до 6 цифр
- Автоматическое сохранение при нажатии OK

### 3. Блокировка интерфейса при открытой панели
**Важно:** Пока панель ввода открыта:
- ✅ Работают только кнопки панели ввода
- ❌ Остальной интерфейс заблокирован
- ❌ Нельзя нажать на другие параметры
- ❌ Нельзя выбрать другое заклинание
- ❌ Нельзя нажать "Назад"

Это сделано специально, чтобы не было случайных кликов и потери данных.

## Интерфейс редактора

### Структура параметра:
```
Название:    [Значение]    [-]  [+]
             (дважды       (минус) (плюс)
              кликабельно)   -1      +1
```

### Пример:
```
Урон:        [20]          [-]  [+]
```

- **Дважды кликните** по `[20]` → откроется панель ввода
- **Один клик** по `[-]` → урон станет 19
- **Один клик** по `[+]` → урон станет 21

## Панель ввода

### Внешний вид:
```
┌──────────────────────┐
│ Введите damage       │
│ ┌──────────────────┐ │
│ │ 20               │ │ ← Поле ввода
│ └──────────────────┘ │
│                      │
│  [1] [2] [3]        │
│  [4] [5] [6]        │ ← Цифровая
│  [7] [8] [9]        │   клавиатура
│  [0]                │
│                      │
│  [Удалить]  [OK]    │
│            [Отмена] │
└──────────────────────┘
```

### Управление:
1. **Кликайте по цифрам** - добавляет цифру к значению
2. **Удалить** - стирает последнюю цифру
3. **OK** - сохраняет и закрывает панель
4. **Отмена** - закрывает без сохранения

## Технические детали

### Изменённые файлы:
- `game/core.py`

### Изменённые функции:

**1. `draw_spell_editor()`:**
- Изменены шаги всех параметров на 1
- Добавлено кликабельное поле значения
- Добавлено отображение панели ввода
- Изменена структура `spell_editor_controls`

**2. `handle_spell_editor_click()`:**
- Добавлена приоритетная обработка панели ввода
- Добавлена блокировка интерфейса при открытой панели
- Добавлено определение двойного клика (450 мс)
- Обработка новой структуры контролов

### Новые переменные:
- `self.spell_num_input` - данные панели ввода `{'param': str, 'value': str}`
- `self.spell_num_buttons` - список кнопок панели `[(kind, value, rect)]`
- `self._spell_edit_last_click` - время последнего клика (для двойного клика)
- `self._spell_edit_last_rect` - последний кликнутый rect (для двойного клика)

### Структура spell_editor_controls:
```python
# Было:
[(param, rect, delta), ...]

# Стало:
[
    (param, 'minus', rect, -1),  # Кнопка минус
    (param, 'plus', rect, 1),     # Кнопка плюс
    (param, 'value', rect, 0),    # Поле значения (для двойного клика)
    ...
]
```
