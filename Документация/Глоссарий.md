# Глоссарий

| Термин | Определение |
| :--- | :--- |
| **Юнит (Unit)** | Основная боевая единица на поле боя. Имеет координаты (x, y), команду (team), здоровье (health), характеристики атаки и защиты, скорость передвижения и инициативу. |
| **Герой (Hero)** | Специальный тип юнита, обладающий заклинаниями, манной (mana), знаниями (knowledge) и силой заклинаний (spell_power). Может применять заклинания в бою. |
| **Команда (Team)** | Принадлежность юнита к одной из сторон конфликта. Значения: 'player1' (первая команда) или 'player2' (вторая команда). |
| **Раса (Race)** | Фракция, к которой принадлежат юниты. Доступные расы: 'human' (Люди), 'undead' (Нежить), 'elf' (Эльфы), 'demon' (Демоны), 'dwarf' (Гномы), 'shadow' (Тени). |
| **Здоровье (Health)** | Текущее количество очков здоровья юнита. При достижении 0 юнит погибает. |
| **Максимальное здоровье (Max Health)** | Максимальное количество очков здоровья, которое может иметь юнит. |
| **Физическая атака (Phys Attack)** | Характеристика, определяющая физический урон, наносимый юнитом при ближнем или дальнем бое. |
| **Магическая атака (Magic Attack)** | Характеристика, определяющая магический урон, наносимый юнитом. |
| **Физическая защита (Phys Defense)** | Характеристика, уменьшающая получаемый физический урон. |
| **Магическая защита (Magic Defense)** | Характеристика, уменьшающая получаемый магический урон. |
| **Сопротивление магии (Magic Resist)** | Процентная характеристика, определяющая вероятность отражения дебаффов и некоторых магических эффектов. |
| **Скорость (Speed)** | Количество клеток, на которое юнит может переместиться за один ход. Также определяет количество очков движения (move_points_left). |
| **Инициатива (Initiative)** | Характеристика, определяющая порядок ходов юнитов в боевой очереди. Чем выше инициатива, тем раньше ходит юнит. |
| **Очередь ходов (Turn Queue)** | Список юнитов, упорядоченный по инициативе, определяющий последовательность ходов в текущем раунде. |
| **Раунд (Round)** | Полный цикл ходов всех юнитов на поле боя. Нумерация начинается с 1. |
| **Очки движения (Move Points)** | Оставшиеся очки движения юнита в текущем ходу. Уменьшаются при перемещении. |
| **Клетка (Cell)** | Базовая единица игрового поля. Размер клетки определяется константой CELL_SIZE (40 пикселей). |
| **Сетка (Grid)** | Игровое поле, разделенное на клетки. Размеры: GRID_WIDTH x GRID_HEIGHT (20x15 клеток при базовом разрешении 800x600). |
| **Заклинание (Spell)** | Магическая способность, доступная героям. Имеет название, стоимость маны, перезарядку, тип цели и описание. |
| **Мана (Mana)** | Ресурс героя, необходимый для применения заклинаний. Восстанавливается каждый раунд на основе знаний (knowledge). |
| **Максимальная мана (Max Mana)** | Максимальное количество маны, которое может иметь герой. |
| **Знания (Knowledge)** | Характеристика героя, влияющая на восстановление маны и силу заклинаний. |
| **Сила заклинаний (Spell Power)** | Характеристика героя, увеличивающая длительность и эффективность применяемых заклинаний. |
| **Перезарядка (Cooldown)** | Количество ходов, которое должно пройти перед повторным использованием заклинания или способности. |
| **Тип цели (Target Type)** | Определяет, на кого может быть применено заклинание: 'ally' (союзник), 'enemy' (враг) или 'any' (любой). |
| **Школа магии (Magic School)** | Категория заклинания, определяющая его природу: 'light' (свет), 'darkness' (тьма), 'fire' (огонь), 'water' (вода), 'earth' (земля), 'air' (воздух) и другие. |
| **Бафф (Buff)** | Положительный эффект, временно улучшающий характеристики юнита (например, увеличение атаки). |
| **Дебафф (Debuff)** | Отрицательный эффект, временно ухудшающий характеристики юнита (например, уменьшение атаки или скорости). |
| **Длительность эффекта (Duration)** | Количество раундов, в течение которых действует бафф или дебафф. |
| **Ближний бой (Melee)** | Тип атаки, при котором юнит атакует врага на соседней клетке. |
| **Дальний бой (Ranged)** | Тип атаки, при котором юнит может атаковать врагов на расстоянии (определяется параметром attack_range). |
| **Дальность атаки (Attack Range)** | Максимальное расстояние в клетках, на котором юнит может атаковать врага. |
| **Контратака (Counterattack)** | Автоматическая атака в ответ на атаку врага. Происходит один раз за раунд (has_counterattacked). |
| **Защита (Defend)** | Действие юнита, увеличивающее физическую и магическую защиту на текущий раунд. |
| **Отряд (Squad)** | Группа юнитов одного типа, представленная одним юнитом на поле. Характеризуется количеством (squad_count) и здоровьем отдельного юнита (unit_hp). |
| **Количество в отряде (Squad Count)** | Число юнитов в отряде. При получении урона уменьшается количество юнитов в отряде. |
| **Здоровье юнита (Unit HP)** | Здоровье отдельного юнита в отряде. При достижении 0 один юнит из отряда погибает. |
| **Тип урона (Damage Type)** | Категория урона: 'physical' (физический), 'magic' (магический), 'poison' (ядовитый), 'fire' (огненный), 'cold' (холод), 'astral' (астральный). |
| **Сопротивление (Resistance)** | Процентное уменьшение урона определенного типа. Типы сопротивлений соответствуют типам урона. |
| **Игровое состояние (Game State)** | Текущий режим игры: 'menu' (меню), 'battle_setup' (настройка боя), 'game' (игра), 'creative' (креативный режим), 'settings' (настройки), 'unit_editor' (редактор юнитов), 'spell_editor' (редактор заклинаний), 'spellbook_editor' (редактор книги заклинаний). |
| **Креативный режим (Creative Mode)** | Режим игры, позволяющий размещать юнитов на поле вручную для тестирования и экспериментов. |
| **Редактор юнитов (Unit Editor)** | Режим редактирования характеристик и параметров юнитов. |
| **Редактор заклинаний (Spell Editor)** | Режим редактирования параметров заклинаний. |
| **Редактор книги заклинаний (Spellbook Editor)** | Режим настройки доступных заклинаний для героев разных рас. |
| **ИИ контроллер (AI Controller)** | Система искусственного интеллекта, управляющая действиями юнитов команды противника. |
| **Менеджер боя (Battle Manager)** | Компонент, управляющий боевой логикой: очередью ходов, инициативой, проверкой победы. |
| **Анимация (Animation)** | Визуальное представление действий юнита: простоя (Idle), движения (Walk), атаки (Attack), получения урона (Hurt), смерти (Death) и других состояний. |
| **Состояние анимации (Animation State)** | Текущая анимация юнита: 'Idle', 'IdleBreath', 'Walk', 'WalkAlt', 'Attack', 'Hurt', 'Death', 'TurnLeft', 'TurnRight' и другие. |
| **Направление взгляда (Facing)** | Направление, в которое смотрит юнит: 1 (вправо) или -1 (влево). Влияет на отображение спрайта. |
| **Процедурная анимация (Procedural Animation)** | Система генерации анимаций юнитов программным способом, без использования готовых спрайтов. |
| **Текстура (Texture)** | Графическое изображение юнита или объекта, загружаемое из файла или генерируемое процедурно. |
| **Кэш текстур (Texture Cache)** | Система кэширования загруженных текстур для оптимизации производительности. |
| **Базовое разрешение (Base Resolution)** | Внутреннее разрешение игрового полотна: 800x600 пикселей. Используется для корректного масштабирования на разных экранах. |
| **Масштаб рендеринга (Render Scale)** | Коэффициент масштабирования для отображения игры на экранах с различными разрешениями. |
| **Смещение рендеринга (Render Offset)** | Смещение по осям X и Y для центрирования игрового полотна на экране. |
| **Полноэкранный режим (Fullscreen)** | Режим отображения игры на весь экран без оконных рамок. |
| **Окно информации о юните (Unit Info Window)** | Интерфейсное окно, отображающее детальную информацию о выбранном юните: характеристики, способности, эффекты. |
| **Тултип (Tooltip)** | Всплывающая подсказка, показывающая информацию о юните или элементе интерфейса при наведении или зажатии правой кнопки мыши. |
| **Событие (Event)** | Сообщение о произошедшем действии в игре (например, "Юнит атаковал", "Применено заклинание"), отображаемое в логе событий. |
| **Режим отладки (Debug Mode)** | Специальный режим, активируемый клавишей F1, для отображения дополнительной информации: дальности хода, дальности атаки, координат и других параметров. |
| **Система отладки (Debug System)** | Комплексная система логирования и мониторинга производительности, состояния игры и диагностики проблем. |
| **Профиль производительности (Performance Profile)** | Набор настроек, определяющих использование системных ресурсов и оптимизаций (например, использование NumPy, аппаратного ускорения). |
| **FPS (Frames Per Second)** | Количество кадров в секунду, отображаемых игрой. Показатель производительности. |
| **Дельта времени (Delta Time)** | Время, прошедшее с предыдущего кадра, используемое для синхронизации анимаций и логики независимо от FPS. |
| **Звук (Sound)** | Аудиофайл, воспроизводимый при определенных событиях (атака, заклинание, смерть юнита и т.д.). |
| **Музыка (Music)** | Фоновая музыка, воспроизводимая в различных режимах игры (меню, бой). |
| **Победитель (Winner)** | Команда, выигравшая бой. Определяется при уничтожении всех юнитов противника или достижении других условий победы. |
| **Игра окончена (Game Over)** | Состояние, когда бой завершен и определен победитель. |
| **Режим наблюдателя (Spectator Mode)** | Режим, в котором игрок не может управлять юнитами, а только наблюдает за боем (например, при игре против ИИ). |
| **Настройки (Settings)** | Конфигурационные параметры игры: разрешение экрана, полноэкранный режим, громкость звука и музыки. |
| **JSON конфигурация (JSON Configuration)** | Файлы настроек в формате JSON, хранящиеся в папке `data/`: `settings.json`, `unit_overrides.json`, `spell_overrides.json`. |
| **Переопределения (Overrides)** | Пользовательские настройки юнитов и заклинаний, загружаемые из JSON-файлов и переопределяющие значения по умолчанию. |
| **Pygame** | Библиотека Python для создания игр и мультимедийных приложений, используемая для рендеринга графики, обработки ввода и воспроизведения звука. |
| **PyInstaller** | Инструмент для упаковки Python-приложений в исполняемые файлы (.exe), используемый для создания Windows-версии игры. |
| **Веб-версия (Web Version)** | Версия игры, адаптированная для запуска в браузере с использованием pygbag. |
| **Проект (Project)** | Корневая директория проекта игры (may_game), содержащая все исходные файлы, ресурсы и документацию. |
