  ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ ДИАГНОСТИЧЕСКОЙ ПРОГРАММЫ ДЛЯ РУНЫ БЕРСЕРКА
═══════════════════════════════════════════════════════════════════════════════

ПРОБЛЕМА: Юниты, следующие после берсерка, тоже становятся берсерками.

РЕШЕНИЕ: Используйте диагностическую программу для выявления проблемы.

═══════════════════════════════════════════════════════════════════════════════
ШАГ 1: ПРИМЕНИТЬ ПАТЧИ
═══════════════════════════════════════════════════════════════════════════════

Запустите в командной строке:

    python patch_berserker_debug.py

Это добавит логирование в код игры. Скрипт создаст резервные копии файлов.

═══════════════════════════════════════════════════════════════════════════════
ШАГ 2: ЗАПУСТИТЬ ИГРУ
═══════════════════════════════════════════════════════════════════════════════

Запустите игру как обычно:

    python main.py

═══════════════════════════════════════════════════════════════════════════════
ШАГ 3: ВОСПРОИЗВЕСТИ ПРОБЛЕМУ
═══════════════════════════════════════════════════════════════════════════════

1. Начните бой
2. Примените руну берсерка на одном юните
3. Продолжите игру несколько ходов
4. Обратите внимание, становятся ли другие юниты берсерками
5. Закройте игру

═══════════════════════════════════════════════════════════════════════════════
ШАГ 4: ПРОВЕРИТЬ ЛОГИ
═══════════════════════════════════════════════════════════════════════════════

Откройте файл berserker_debug.log - там будет детальный лог всех операций.

═══════════════════════════════════════════════════════════════════════════════
ШАГ 5: СГЕНЕРИРОВАТЬ ОТЧЕТ
═══════════════════════════════════════════════════════════════════════════════

Запустите:

    python -c "from berserker_debug import generate_report; generate_report()"

Или создайте файл generate_report.py:

    from berserker_debug import generate_report
    generate_report()

И запустите:

    python generate_report.py

Отчет будет сохранен в berserker_debug_report.txt

═══════════════════════════════════════════════════════════════════════════════
ЧТО ИСКАТЬ В ОТЧЕТЕ
═══════════════════════════════════════════════════════════════════════════════

1. SUSPICIOUS_STATE - юниты с неправильным состоянием
   (например, команда берсерка, но нет активного флага)

2. TEAM_CHANGE - неожиданные изменения команд

3. QUEUE_PREP - сколько берсерков в очереди и их состояние

4. Применения руны - проверьте, применяется ли она на правильные юниты

5. АНАЛИЗ ХОДОВ - показывает:
   - Кто управлял каждым юнитом (игрок, AI, берсерк-логика)
   - Проблемные ходы (берсерк управлялся не берсерк-логикой)
   - Ходы с подозрительными контроллерами

6. AI_DECISION_ON_BERSERKER - если AI пытался управлять берсерком
   (это критическая ошибка!)

═══════════════════════════════════════════════════════════════════════════════
ОТКАТ ИЗМЕНЕНИЙ (если нужно)

═══════════════════════════════════════════════════════════════════════════════
ВАЖНО
═══════════════════════════════════════════════════════════════════════════════

- Логи пишутся в реальном времени
- Можно открыть berserker_debug.log во время игры для мониторинга
- Все логи включают ID юнита для отслеживания конкретного объекта
- После анализа проблемы можно откатить патчи
