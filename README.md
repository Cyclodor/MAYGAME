# Фэнтези Стратегия

Простая 2D стратегия в фэнтези сеттинге, созданная на Python с использованием Pygame.

## Описание игры

В игре участвуют два героя, каждый со своей армией из 7 юнитов. Игроки по очереди перемещают свои юниты по полю боя, используя сетку для навигации. Герои обладают специальными заклинаниями, которые могут использовать в бою.

## Установка

1. Убедитесь, что у вас установлен Python 3.7 или выше
2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Запуск игры

```bash
python main.py
```

## Управление

- Левая кнопка мыши: выбор и перемещение юнитов
- Юниты могут перемещаться только на определенное количество клеток за ход
- Юниты могут атаковать врагов на соседних клетках
- Ходы чередуются между игроками
- Клавиши 1-3: использование заклинаний героя (только для героев)

### Отладочные функции

- **F1**: Включение/выключение режима отладки
- **F2**: Отладка дальности хода
- **F3**: Отладка дальности атаки
- **F4**: Отладка элементов интерфейса
- **F5**: Отладка дальнобойных атак
- **F6**: Тестирование логики атаки

## Заклинания

1. Огненный шар (Клавиша 1)
   - Наносит урон вражескому юниту
   - Дальность: 3 клетки
   - Перезарядка: 2 хода

2. Исцеление (Клавиша 2)
   - Восстанавливает здоровье союзному юниту
   - Дальность: 2 клетки
   - Перезарядка: 3 хода

3. Щит (Клавиша 3)
   - Увеличивает защиту союзного юнита
   - Дальность: 1 клетка
   - Перезарядка: 4 хода

## Особенности

- Два героя с уникальными способностями
- Армии из 7 юнитов с каждой стороны
- Система заклинаний с перезарядкой
- Пошаговая стратегия
- Сетка для перемещения
- Полоски здоровья юнитов
- Система защиты от урона
- Определение победителя
- Визуальный интерфейс с информацией о юнитах "# MAYGAME"
