# Диагностическая программа для руны берсерка

Эта программа поможет найти проблему, когда состояние берсерка "перетекает" на других юнитов.

## Файлы

1. **berserker_debug.py** - Основной модуль отладки, который логирует все операции с берсерком
2. **patch_berserker_debug.py** - Скрипт для автоматического добавления логирования в код игры

## Использование

### Шаг 1: Применить патчи

Запустите скрипт патчирования:

```bash
python patch_berserker_debug.py
```

Это добавит логирование в следующие файлы:
- `game/spells.py` - логирование применения руны берсерка
- `game/units.py` - логирование окончания хода и снятия эффекта
- `game/core.py` - логирование проверок берсерка и подготовки очереди

**Важно:** Скрипт создаст резервные копии файлов (`.backup`). Если что-то пойдет не так, вы можете восстановить файлы из резервных копий.

### Шаг 2: Запустить игру

Запустите игру как обычно:

```bash
python main.py
```

### Шаг 3: Воспроизвести проблему

1. Начните бой
2. Примените руну берсерка на одном юните
3. Продолжите игру несколько ходов
4. Обратите внимание, становятся ли другие юниты берсерками

### Шаг 4: Проверить логи

После игры проверьте файл `berserker_debug.log` - там будет детальный лог всех операций с берсерком.

### Шаг 5: Сгенерировать отчет

Запустите:

```bash
python -c "from berserker_debug import generate_report; generate_report()"
```

Или в Python:

```python
from berserker_debug import generate_report
generate_report()
```

Это создаст файл `berserker_debug_report.txt` с анализом проблемы.

## Что логируется

Программа отслеживает:

1. **Применение руны берсерка** - когда и на кого применена
2. **Изменения команды** - когда команда юнита меняется на/с берсерка
3. **Проверки берсерка** - все места, где проверяется, является ли юнит берсерком
4. **Окончание хода** - когда уменьшается счетчик ходов берсерка
5. **Подготовка очереди** - какие юниты в очереди и их состояние
6. **Подозрительные состояния** - юниты с неправильными флагами берсерка

## Анализ отчета

В отчете ищите:

1. **SUSPICIOUS_STATE** - юниты с неправильным состоянием (например, команда берсерка, но нет активного флага)
2. **TEAM_CHANGE** - неожиданные изменения команд
3. **QUEUE_PREP** - сколько берсерков в очереди и их состояние

## Откат изменений

Если нужно откатить патчи:

```bash
# Для каждого файла
cp game/spells.py.backup game/spells.py
cp game/units.py.backup game/units.py
cp game/core.py.backup game/core.py
```

## Примеры проблем, которые может выявить программа

1. **Проблема с копированием объектов** - если ID юнитов совпадают, значит объекты копируются неправильно
2. **Проблема с очисткой состояния** - если флаги берсерка остаются после окончания эффекта
3. **Проблема с очередью** - если в очереди появляются юниты с неправильным состоянием
4. **Проблема с проверками** - если проверки берсерка работают неправильно

## Дополнительная информация

Логи сохраняются в реальном времени, так что вы можете следить за ними во время игры (если открыть файл в текстовом редакторе с автообновлением).

Все логи включают:
- Временную метку
- Тип события
- ID юнита (для отслеживания конкретного объекта)
- Позицию юнита
- Дополнительные данные
